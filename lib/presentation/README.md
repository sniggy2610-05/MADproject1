# presentation

Flutter screens and widgets.

- `theme/` - colors and fonts (burgundy, ivory, parchment; serif headings, sans-serif controls)
- `router.dart` - go_router configuration
- `screens/` - splash, home, case intro, scenes, evidence, notebook, board, hints, suspects, accusation, result, settings
- `widgets/` - shared widgets, including the Evidence Board
